# Hager Hassan Marzouk | Front-End Developer

A responsive personal portfolio introducing Hager Hassan Marzouk, a front-end developer focused on React and modern web experiences. The site brings together an introduction, services, technical skills, training, selected projects, and contact links.

## Features

- Responsive layout for desktop and mobile
- Light and dark themes, with the selected theme saved in the browser
- Mobile navigation drawer and scroll-aware section navigation
- Contact links and email-copy interaction
- Project cards linking to live work
- No build tools, frameworks, or package installation required

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Plus Jakarta Sans

## Run Locally

Clone the repository and open `index.html` in a browser. For local development, open the folder in Visual Studio Code and use any static-file server.

```bash
git clone https://github.com/hagarhasan/Portfolio.git
cd Portfolio
```

## Deployment

This is a static website and can be hosted with GitHub Pages:

1. Open the repository's **Settings** on GitHub.
2. Go to **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then save.

After GitHub Pages finishes deploying, the site will be available at:

<https://hagarhasan.github.io/Portfolio/>
